# Rastreabilidade: casos de borda e requisitos

Este documento liga cada **caso de borda E-01…E-34** e cada **requisito RF-01…RF-12** da [SPEC.md](../SPEC.md) a testes automatizados que **existem de fato** no repositório, ao roteiro manual ([TESTE-MANUAL.md](TESTE-MANUAL.md)) ou a um motivo de "não verificável".

Os nomes de teste abaixo são nomes reais de métodos. Para listar/rodar qualquer um:

```powershell
dotnet test tests\MediaRescue.Core.Tests --filter "FullyQualifiedName~E15_DestinationFillsUp_PausesAndCleansPartial"
```

**Projetos:** `Core` = `MediaRescue.Core.Tests` (lógica com fakes e injeção de falhas, sem hardware) · `App` = `MediaRescue.App.Tests` (ViewModels, sem janela) · `Int` = `MediaRescue.Integration.Tests` (a pasta `EndToEnd\` roda o fluxo inteiro — motor, ISO montada, destino real e, nos testes de ViewModel, a tela sem janela — e é indicada como *E2E*; APIs reais do Windows: ISO montada com `Mount-DiskImage`, sistema de arquivos real, ffprobe; os testes marcados *(M)* usam disco montado e os *(F)* precisam de `tools\` + `.testmedia\`; quando o ambiente não permite aparecem como **ignorados (skipped) com o motivo**, nunca como aprovados).

## O que cada camada prova (e o que ainda não foi provado)

| Camada | Prova | Não prova |
|---|---|---|
| Unitária (`Core`, `App`) | Lógica de cópia, recuperação de erros, verificação, nomes, catálogo, retomada, estados da interface, com leitores/destinos simulados. | Que o hardware real se comporta como o simulado. |
| Integração (`Int`) | P/Invoke, leitura *overlapped* com timeout e cancelamento, ISO montada como unidade de CD, notificações de dispositivo, sistema de arquivos real. | Comportamento de mídia física (riscos reais, leitor USB real, bandeja). |
| Manual (`TESTE-MANUAL.md`) | — (roteiro para o usuário). | **Nenhum passo foi executado em leitor real até agora**: o leitor `D:` da máquina de desenvolvimento reportou "sem mídia" com disco inserido. |

Legenda da coluna **Situação**: **A** = coberto por teste(s) automatizado(s) · **A+M** = automatizado e também no roteiro manual · **NV** = não verificável (com motivo).
